MOZA STUDIO ADVANCED V10 — PREFLIGHT REVIEW
6 November 2026

DASAR: Moza Studio Advanced V9 (mencakup semua fitur V8).

FITUR BARU
1. Tombol '✓ Preflight' pada toolbar Design Editor.
2. Panel pemeriksaan lokal, read-only, untuk konten proyek sebelum publish.
3. Pengecekan gambar (alt text, placeholder aset), video placeholder,
   URL berbahaya dan alamat relatif yang perlu diperiksa manual.
4. Pengecekan Smart Filter: judul/kategori kosong, item duplikat,
   URL media, video dengan format yang tidak dikenali, konten kosong.
5. Pengecekan Accordion / Sliding Tabs (item dan judul kosong).
6. Nama halaman duplikat dan tujuan halaman hilang pada interaksi sederhana.
7. Menggabungkan temuan metadata dari Project Audit V8 (tanpa mengubahnya).
8. Filter tingkat temuan: Error, Perlu dicek, Informasi.
9. Ekspor laporan CSV/JSON dengan lokasi, kode, keterangan, dan rekomendasi.
10. Navigasi keyboard Escape/Tab dan jumlah temuan per tingkat.

FILE BERUBAH DARI V9
- index.html: judul + pemanggilan addon V10.
FILE BARU
- moza-preflight.js
- moza-preflight.css
- CATATAN_ADVANCED_V10.txt
- PANDUAN_DEPLOY_V10.txt

TIDAK DIUBAH
- Editor Atelier inti, login, RSVP, Google Sheets, Supabase, cloud,
  publish dan data pengguna. Pemeriksaan bersifat READ-ONLY.

BATASAN
- Pemeriksaan tidak melakukan fetching media/tautan; URL yang tampak valid
  masih dapat berstatus 404 atau memerlukan izin login.
- Tidak menguji performa perangkat nyata, UX, RTL, SEO lengkap, a11y penuh,
  koneksi cloud, pengiriman RSVP, atau hasil publish situs.
- Beberapa temuan (misalnya gambar placeholder) mungkin memang disengaja.
- Tidak ada auto-fix karena koreksi konten memerlukan keputusan pengguna.

PENGUJIAN
- Chromium terisolasi: temuan alt, tautan berbahaya, video tidak langsung,
  kategori kosong, filter severity, ekspor CSV/JSON, dan close Escape.
- Regresi V7–V8, impor V9 via file chooser/Undo, widget lama dan parsing
  CSV di V9/V10 lulus.
- Full app melalui http://127.0.0.1 terhalang kebijakan browser pengujian.

Backup sebelum deploy dan uji pada staging. Validasi melalui hosting nyata.
