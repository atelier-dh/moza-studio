# Moza Studio V14.9.4 — Responsive Music Speaker

## Changes
- Independent speaker button size for Desktop, Tablet and Mobile.
- Independent inner icon size for Desktop, Tablet and Mobile.
- Canvas speaker preview follows the selected editor breakpoint.
- Published/exported HTML applies responsive sizing at Desktop >1024px, Tablet 641–1024px, and Mobile <=640px.
- Existing projects without responsive values inherit their previous global `music.size` and `music.isz` values; Tablet and Mobile receive sensible proportional defaults.
- Existing button position, offsets, shape, color, audio source, autoplay, loop and custom icon settings remain intact.

## Backend
No Supabase schema, Edge Functions, RSVP data, or Apps Script changed.
