PERUBAHAN BARU V7
1. Smart Filter memiliki pencarian judul/isi/kategori (opsional lewat Properties),
   placeholder yang bisa diubah dan jumlah item hasil yang terlihat.
2. Kategori yang hanya berbeda huruf besar/kecil tidak menjadi tombol ganda.
3. Smart Filter lama bisa di-upgrade lewat Properties > Update HTML Widget,
   atau tombol Audit > Upgrade HTML widget untuk beberapa widget sekaligus.
   Tindakan ini perlu persetujuan; perubahan manual pada embed HTML widget
   bisa tertimpa. Gunakan Undo jika perlu.
4. Auto Layout mengatur padding pada group sempit agar elemen tetap terbaca.
   Tidy Grid membatasi kolom sesuai area yang benar-benar tersisa.
5. Responsive Grid menyesuaikan jumlah kolom efektif pada group sempit agar
   lebar minimum sel tidak menabrak sisi group. Nilai kolom pilihan tidak berubah.
6. Hapus master Component sekarang juga membersihkan daftar Variant Set dari
   tautan yang sudah tidak punya master. Varian lain tetap dipertahankan.
7. Hapus Design Variable membersihkan object binding elemen jika kosong.
8. Tombol "✦ Audit" memindai jumlah halaman/section/elemen, library design,
   duplicate ID, referensi rusak, layout ganda dan widget yang butuh sinkron.
9. Audit > Rapikan referensi aman menghapus metadata yang kehilangan sumber,
   bukan menghapus elemen visual. Butuh konfirmasi dan bisa Undo.
10. Index.html hanya berubah pada judul versi dan tambahan 2 aset Audit V7.
    Kode asli login, publish, Supabase, RSVP, dan cloud tidak diubah oleh patch.

CARA DEPLOY
1. Backup ZIP V6 dan backup/export data project sebelum replace file di hosting.
2. Ekstrak isi ZIP V7 ke akar website/hosting statis, pertahankan index.html
   dan seluruh moza-*.js/moza-*.css pada folder yang sama (jangan hanya index).
3. Hard refresh browser (Ctrl+Shift+R) agar cache aset V6 tidak digunakan.
4. Buka project salinan, cek Canvas Desktop/Tablet/Mobile dan Preview.
5. Buka tombol "✦ Audit" dari editor. Periksa isu dan hanya klik perbaikan
   jika kamu sudah meninjau konsekuensinya.
6. Untuk Smart Filter lama, pilih objek Smart Filter, buka Properties,
   klik "Update HTML Widget" jika ingin mengaktifkan pencarian terbaru.
   Alternatif: Audit > Upgrade HTML widget untuk semua widget yang perlu upgrade.
7. Tes simpan/reload project, Undo/Redo, eksport/publish, RSVP, login,
   serta integrasi backend sesuai konfigurasi situsmu.
